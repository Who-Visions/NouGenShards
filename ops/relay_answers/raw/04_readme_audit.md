## (a) Ordered Protocol  
1. **Validate code base** – `python -m compileall src/ nougen_shards/` → ensures source truth compiles.  
2. **Regenerate README & CHANGELOG** – run `./tools/generate_docs.py` (uses `source` and `history` modules).  
3. **Scan for drift** – execute `./tools/drift_audit.py` against the freshly generated docs.  
4. **Classify & auto‑fix** – apply safe auto‑generation rules (see (c)).  
5. **Manual review** – edit only non‑auto‑safe sections per (d).  
6. **Commit & push** – include generated docs, updated drift‑report, and a `drift: fixed` tag.  

---

## (b) DRIFT CLASS Taxonomy & Deterministic Detector  

| Class | Description | Deterministic Detector |
|-------|-------------|------------------------|
| **COUNT_STALE** | Mismatched static numbers (e.g., “19 tools” vs actual count) | Parse `src/nougen_shards/mcp.py` for `@mcp.tool()` → compare with reported count. |
| **ENDPOINT_STALE** | Out‑of‑date endpoint URLs or route names | Grep `fleet.py` route table → match against doc‑listed endpoints. |
| **INSTALL_STEP_STALE** | Wrong “pip install nougen” or “docker run” commands | Extract install scripts from `tools/…` & `README.md` line starting with “Install”. |
| **ENV_VAR_STALE** | Deprecated env‑var names or missing vars | Scan `keymaker.py`, `vram_gate.py`, `tenants.py` for os.getenv usage → compare with doc list. |
| **TERMINOLOGY_STALE** | Incorrect term usage (e.g., “relays” vs “RELAYS”) | Regex on `README.md` for known term patterns; cross‑check with canonical set (see (d)). |
| **DEAD_LINK_STALE** | Broken URLs or missing sections in docs | Render `README.md` with `markdown-link-check` → flag non‑200 responses. |
| **CONFIDENCE_STALE** | Confidence labels in `assurance.py` out‑of‑sync with latest verdicts | Compare `assurance.py` emitted labels against latest `*.json` verdict files. |

All detectors read **executable truth** (`SOURCE`) and produce a deterministic integer score (0 = no drift, 1 = drift).  

---

## (c) Auto‑Generated vs Hand‑Written Classes  

| Safe for Auto‑Gen | Must Remain Hand‑Written |
|-------------------|--------------------------|
| `COUNT_STALE` (numeric aggregates) | `TERMINOLOGY_STALE` (semantic meanings, branding) |
| `ENDPOINT_STALE` (list extraction) | `DEAD_LINK_STALE` (contextual relevance) |
| `ENV_VAR_STALE` (schema extraction) | `CONFIDENCE_STALE` (interpretation of confidence) |
| `INSTALL_STEP_STALE` (static command list) | All **DRIFT REPORT** narrative elements |
| `SOURCE`‑derived data (`SHARDS`, `RELAYS`, `CHANGELOG` metadata) | Any **canonical terminology** definitions (see (d)) |

---

## (d) Canonical Cross‑Repo Terminology  

- **README** – *current truth* (the single source of present‑state facts).  
- **CHANGELOG** – *historical motion* (chronological change log).  
- **RELAYS** – *operational motion* (runtime channels: `relay_open/read/create/ack/…`).  
- **SHARDS** – *durable memory* (persistent memory blocks: `link_shards`, `promote_context_to_shard`, etc.).  
- **SOURCE** – *executable truth* (code, scripts, compiled modules).
