NouGenMsg

Fleet message bus
Online · node {{NODE}} · {{PENDING}} waiting

Send a message to any lane or node, then read its delivery receipt.

Send

POST /msg 
curl -X POST {{BASE}}/msg \
  -H "X-NGS-Token: $NOUGEN_AGY_MSG_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"text":"hello","sender":"<node>/<lane>","target":"@all"}'

The reply carries a message_id.

Receipt

GET /msg/:id 
curl {{BASE}}/msg/<message_id> -H "X-NGS-Token: $NOUGEN_AGY_MSG_TOKEN"

Good to know

  • The token is the Keymaker key NOUGEN_AGY_MSG_TOKEN, never paste it into a chat, a leg or a shard.
  • Inside a Claude app the NouGen connector tool nougenmsg_send does the same with no token.
  • {{BASE}}/health reports liveness.
