Outbound-only relay

Reach your node from anywhere. Open no ports.

Your computer dials out to the relay once and stays connected. The relay forwards web requests to it, and nothing else gets in.

Read the spec How it connects

How it works

Three steps, one open socket

  1. STEP 01

    Your node connects out over a WebSocket and authenticates with its token.

  2. STEP 02

    A visitor requests your node’s address.

  3. STEP 03

    The relay hands the request down the open socket and returns the answer.

Defense in depth

Built to distrust

  • 01

    Hashed credentials

    The relay stores only a hash of each node’s token.

  • 02

    Checked responses

    Everything a node sends back is checked before it reaches the visitor.

  • 03

    Capped sizes

    Request and response size are capped.

  • 04

    No roll call

    A node must prove its token even to ask its own status, so nobody can list who is online.

By default:

  • 8 MiBbody cap, request and response
  • 30 swait for a node’s answer
  • 20 snode heartbeat
  • 90 ssilent node is dropped
